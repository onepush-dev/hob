# Hob on Railway

Hob — a self-hosted personal assistant that runs background jobs and delegates work to coding agents. Deploy on Railway with one click.

This repository packages the official [Hob](https://github.com/FFatTiger/hob) image (`ghcr.io/ffattiger/hob:1.5.0`, MIT) for Railway. Independent community packaging, not affiliated with the Hob project.
